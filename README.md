# 康鈣 C 片 3D 溶解實驗室

互動式課堂模擬。調整片劑質量、水溫、水量與攪拌速度後，可觀看 3D 燒杯中的片劑下落、發泡、縮小及水色變化。完成的實驗會保存在瀏覽器本機。

## 本機預覽

```sh
python3 -m http.server 8768 --directory dist
```

然後開啟 `http://127.0.0.1:8768/`。網站使用本地存放的 Three.js ES module，無須在訪客裝置安裝套件。

## 模型說明

反應時間由質量、水溫、水量及攪拌速度計算，再以漸進曲線呈現片劑縮小。氣泡數量與橙色程度隨模擬進度變化。這是教學視覺化模型，不是康鈣 C 產品的實測溶解時間、成分分析或醫療建議。
